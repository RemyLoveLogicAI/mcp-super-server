## Overview

This TypeScript module provides a small SDM (system daemon manager) utility object and a few convenience exports to start, stop, restart, and query the status of system-level daemons on macOS using launchctl. The SDM object exposes methods for invoking launchctl actions, gating execution with a simple signed capability token, lightweight memory monitoring that can stop and restart daemons when RSS exceeds a ceiling, verifying firewall/integration via an Aegis CLI invocation, and a mocked secret injection routine that writes secrets to a restrictive temporary file.

The file also exports helper functions (start, stop, restart, status) that wrap the SDM methods with the withVault token check. Note that several behaviors are explicit placeholders or mock implementations (token verification, secret piping, and monitoring) rather than full production integrations; the code uses child_process to run external commands and the filesystem for a simple secrets placeholder.
