## Overview

This directory contains a TypeScript module that provides a compact SDM (system daemon manager) utility focused on interacting with macOS launchctl. The root-level file sdm.ts implements operations to start, stop, restart, and query the status of system-level daemons, and exports convenience helpers for those operations. The module is intended to be imported by other parts of the codebase that need programmatic control over macOS launchd-managed services.

There are no subdirectories under this directory; its structure is intentionally minimal and centered on a single focused utility. The role of this directory in the larger system is to encapsulate platform-specific daemon control logic (macOS/launchctl) so that other code can call a concise API for lifecycle operations on system daemons without embedding launchctl invocation details directly throughout the codebase.


### File Organization

A single-file directory: all functionality for macOS daemon control is consolidated into sdm.ts to keep platform-specific launchctl logic isolated and easy to locate. This flat structure avoids scattering small utilities across multiple files.
