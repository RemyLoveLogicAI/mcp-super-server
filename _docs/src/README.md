## Overview

This directory currently contains no root-level source files and is organized to host small, focused utility modules used by higher-level code. The primary content is the tools/ subdirectory, which contains a TypeScript module (sdm.ts) implementing a compact SDM (system daemon manager) utility that interfaces with macOS launchctl to start, stop, restart, and query system-level daemons. The README here reflects that the directory's role is to collect small system-management helpers rather than application business logic.

The tools/ subdirectory provides a single exported helper module that higher-level code can import when it needs to manage macOS launchctl-managed daemons. Together, the (absent) root-level files and the tools/ module form a small support library: the root-level location is a logical place to add additional utilities in future, while tools/sdm.ts is the concrete implementation currently available. This directory acts as an implementation detail provider for other parts of the repository that require system daemon lifecycle operations on macOS.


### File Organization

The directory is organized hierarchically: no files at the root of src right now, with a dedicated tools/ subdirectory to contain utility modules. This separation keeps small, system-focused utilities isolated from application code and makes it clear where to add similar helper modules in the future.
